# 城市生活有意思

移动端互动海报：[打开网页](https://lixinisydney-cloud.github.io/city/)。

- 拖动放大镜，擦开鸽子、盆栽、猫咪和相机，观看透明循环视频。
- “重新玩”恢复海报；“暂停动画”同时暂停文字和视频。
- “保存图片”导出当前擦开状态的 PNG，手机可长按图片保存。

`index.html` 已内嵌全部图片与视频，无须安装依赖或构建，下载后也可在浏览器中打开。

GitHub Pages 从 `gh-pages` 分支根目录发布。`main` 分支保留同一版网页；后续发布时同步更新两个分支中的 `index.html`。

视频使用原 MOV 提取的真实透明遮罩，在 Canvas 中合成，保留物体颜色和柔边。
