# 互动公园

直接用浏览器打开 `index.html`，无需安装依赖。也可在此目录运行 `python3 -m http.server 8000` 后通过本地服务器访问。

鼠标移入喷泉、画架（包含调色盘）、草丛或花朵时，相应视频从头静音循环播放；移出后恢复静态背景。触屏点击播放，再次点击同一区域停止。支持 Tab 切换区域、Enter/空格播放、Esc 停止。

对应素材：喷泉 → penquan.mp4，画 → hua.mp4，草 → cao.mp4，花 → hua (2).mp4（保存为 hua-2.mp4）。视频包含完整场景，因此播放时覆盖整个画面。背景 park.png 提取自喷泉视频的第一帧，与提供的公园图为同一场景；如需替换原始高清 park 图，覆盖 assets/park.png，保持 16:9 比例即可。

网页保持原图比例，窗口变化时热点会同步缩放，不裁切画面。请保留 index.html 与 assets 文件夹的相对位置。
